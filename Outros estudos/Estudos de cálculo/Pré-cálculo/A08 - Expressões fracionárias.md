# Expressões fracionárias
>[!quote] Definição de expressões algébricas
> - São expressões matemáticas formadas por numeros (numéricas), números e letras (algébricas), ou somente letras (incognitas);
> 	- Para incógnitas que aparecem no denominador deve ser ter maior atenção para que o denominador não seja igual a zero.
> - Uma expressão fracionária é o quociente entre duas expressões algébricas.

## Tipos Principais
### Numéricas
- Contêm números e operações com frações, como: $$\frac{1}{2}+\frac{3}{4}$$
### Algébricas (fração algébrica)
- Possuem letras (incógnitas) no numerador e /ou denominador, como: $$\frac{x-1}{x} \text{ ou } \frac{x^2-4}{x+2}$$
>[!warning] Regra essencial
>- Denominador **≠** 0: o denominador nunca pode ser zero, pois a divisão por zero é indefinida, logo: $$\text{Exemplo: } \frac{x-1}{x} \text{ em que } x \in \mathbb{R}^*$$
## Exemplos de resolução
- 1. $$\frac{3x}{4x} = \frac{3}{4}$$
- 2. $$\frac{9x^2}{6x^1} = \frac{3x}{2} \text{ seguindo a regra: } \boxed{\frac{a^m}{a^n} = a^{m-n}}$$
- 3. $$\frac{x^5y^{-4}z^3}{x^3y^5z^{-6}} = \frac{x^{5-3} .{y^{-4-5}.z^{3+6}}}{1} = x^2.y^{-9}.z^9 = \boxed{\frac{x^2.z^9}{y}}$$
